<div class="pb-hero-demo">

```sh frame="terminal" title="deterministic by design"
builder execute default:hello --name=payments
```

```txt
~ services.txt
~ src/services/payments.ts
✓ done — 2 modified
```

<div class="pb-hero-demo__caption">

Run it again with `--name=orders` and `services.txt` grows by one
line. Re-run the *same* name and it fails closed, so nothing is written twice.
The same schematic with the same input always produces the same bytes.
