```sh frame="terminal" title="determinista por diseño"
builder execute default:hello --name=payments
```

```txt
~ services.txt
~ src/services/payments.ts
✓ done — 2 modified
```

<p class="pb-hero-demo__caption">
	Ejecútalo de nuevo con <code>--name=orders</code> y <code>services.txt</code> crece una
	línea. Vuelve a ejecutarlo con el <em>mismo</em> nombre y la ejecución se rechaza (fail-closed), así que nada
	se escribe dos veces. El mismo schematic con la misma entrada siempre produce los mismos bytes.
</p>
