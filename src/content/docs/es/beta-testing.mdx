---
title: Únete a la beta
description: Postúlate para probar Project Builder y enviar feedback desde tu cliente MCP.
---

El programa beta de Project Builder es para personas que quieran probar flujos reales de generación de proyectos y reportar problemas antes de un lanzamiento público.

## Postúlate

1. Abre la página de postulación.
2. Continúa con la cuenta de GitHub que usarás con tu cliente MCP.
3. Confirma tu postulación. Tu identidad verificada de GitHub y tu correo se agregan a la lista privada de revisión.
4. Espera la aprobación. Las postulaciones se revisan manualmente.
5. Cuando seas aprobado, recibirás un correo de `beta@pbuilder.dev` con las instrucciones para iniciar sesión en el MCP.

[Postúlate para ser beta tester](https://project-builder-schematics.github.io/feedback-dashboard/?mode=apply)

Enviar una postulación no concede acceso inmediato. Nunca compartas el correo de aprobación ni el enlace de autenticación.
