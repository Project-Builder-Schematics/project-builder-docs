Project Builder's beta program is for people who want to test real project-generation workflows and report problems before a public release.

## Apply

1. Open the beta application page.
2. Continue with the GitHub account you will use with your MCP client.
3. Confirm your application. Your verified GitHub identity and email address are added to the private review list.
4. Wait for approval. Applications are reviewed manually.
5. When approved, you will receive an email from `beta@pbuilder.dev` with the MCP sign-in instructions.

[Apply to become a beta tester](https://project-builder-schematics.github.io/feedback-dashboard/?mode=apply)

Submitting an application does not grant immediate access. Never share an approval email or authentication link.
