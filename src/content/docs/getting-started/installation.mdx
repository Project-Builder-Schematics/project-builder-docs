The only thing you install on your machine is the **`builder` CLI**, which ships the engine.
The SDK is added per project, usually automatically.

Run `builder --version` to check your installed CLI version.

## macOS / Linux

With [Homebrew](https://brew.sh) installed, grab the CLI (the `builder` binary) from the
tap:

```sh
brew install project-builder-schematics/tap/pbuilder
```

<Aside type="caution" title="Linux / WSL2">
This needs a recent Homebrew. The cask install is verified on Homebrew 6.x; older
versions refuse casks on Linux.
</Aside>

No Homebrew at all? Download the per-platform tarball from the
[tap's releases](https://github.com/Project-Builder-Schematics/homebrew-tap/releases)
(`pbuilder_<version>_linux_amd64.tar.gz` and friends) and put `builder` on your `PATH`.

You don't need to install [Bun](https://bun.sh). Schematics run in a Bun sidecar, and the
CLI provisions it: the first time it runs a schematic, it downloads a pinned Bun release,
checks it against a known SHA-256 hash and caches it. That first run needs network
access; later runs use the cache.

<Aside type="note">
That Bun is only the schematics' runtime and never goes on your `PATH`. Your project
keeps whatever package manager and tooling it already uses (npm, pnpm, yarn, …).
</Aside>

## Windows

<Aside type="caution" title="Not yet supported">
Windows builds of the CLI are on the roadmap; in the meantime the supported path on
Windows is WSL2 (Ubuntu), using the Linux instructions above.
</Aside>

## The SDK itself

You normally don't install it by hand: `builder init` adds `@pbuilder/sdk` to your
project's `devDependencies` automatically. To add it manually, use whichever package
manager your project already uses:

```sh
npm install -D @pbuilder/sdk    # or: pnpm add -D / yarn add -D / bun add -d
```

Just trying Project Builder out? You can run it without declaring the SDK in
`package.json`. See [Evaluate without adopting the SDK](/guides/evaluate-without-sdk/).

With the CLI in place, you're ready for
[your first schematic](/getting-started/your-first-schematic/).
